# UniMatokeo

[![Nuxt UI](https://img.shields.io/badge/Made%20with-Nuxt%20UI-00DC82?logo=nuxt&labelColor=020420)](https://ui.nuxt.com)

UniMatokeo is a simple, privacy-focused web app that helps students access their academic results from multiple Kenyan universities and colleges in one place. Instead of navigating complex institutional portals or queuing at notice boards, students can select their institution, enter their admission number, and view their report card instantly. The app fetches results directly from each institution's official portal, stores no user data, and uses only a single functional cookie for consent.
